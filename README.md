# SmallCraft

Bare-bones Minecraft server for ESP32.

## Features
- 16x16x16 world
- Multiplayer
- Block placement and breaking
- Full world synchronization
- Chat

## How to use
1. Download `SmallCraft.ino`
2. Change `STA_SSID` and `STA_PSK` to your Wi-Fi (or use AP)
3. Upload to ESP32
4. Connect with Minecraft Beta 1.7.3 to the ESP32's IP
